# Gab Lacarriere Methodology — Candidate & Evidence Register

**Purpose:** private-facing review layer between raw evidence and the canonical `design/gab-lacarriere-methodology.md`.

This file prevents useful ideas from being lost while preventing every observation from becoming doctrine. It stores only de-identified summaries. Never place student names, private quotations, meeting URLs, or identifiable lesson details here.

## Status model

- **Candidate** — promising generalizable idea, below canonical threshold.
- **Supported candidate** — repeated evidence exists, but wording/relationship still needs review.
- **Ready for promotion** — satisfies the evidence threshold or Gab has explicitly adopted it.
- **Promoted** — incorporated into the canonical methodology and relevant products.
- **Deferred** — useful but intentionally not part of the method yet.
- **Rejected** — considered and explicitly not adopted; retained to prevent accidental reintroduction.

## Evidence strength

For each candidate, track:

- number of distinct teaching notes/classes;
- number of distinct contexts (group class, private, mentorship, teacher training, self-practice, etc.);
- whether Gab explicitly adopted it;
- whether current website/tools already operationalize it;
- whether external research supports, qualifies, or contradicts it.

Evidence counts are about independent contexts, not repeated mentions inside one transcript.
